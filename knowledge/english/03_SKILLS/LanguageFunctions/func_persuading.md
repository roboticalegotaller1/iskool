# Language Function: Persuading and Influencing Opinions

## 1. Repertorio Expresivo
- **Nivel B1 (Persuasión directa y apelación a beneficios prácticos):**
  - *"If we start separating school waste now, we can reduce our landfill footprint dramatically."*
  - *"Don't you agree that having digital textbooks makes learning much lighter and accessible?"*
  - *"Think about the long-term benefits: learning to code now will open doors to university internships."*
- **Nivel B2 (Persuasión retórica, énfasis y apelación ética):**
  - *"Surely the undeniable reality of climate disruption calls for immediate collective accountability."*
  - *"What we must recognize is that investing in public infrastructure generates lasting socioeconomic equity."*
  - *"It is precisely this proactive mindset that separates visionary projects from short-sighted policies."*

## 2. Pautas Pedagógicas
- Entrenar el uso de oraciones hendidas (*cleft sentences: "What we need is..."*) para dar énfasis persuasivo.
- Desarrollar la modulación vocal (énfasis en palabras clave) sin caer en agresividad verbal.
