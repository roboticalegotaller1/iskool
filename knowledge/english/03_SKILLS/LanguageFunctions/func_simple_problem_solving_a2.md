# Language Function: Simple Collaborative Problem Solving (A2)

## 1. Repertorio Expresivo
- **Exponer el problema cotidiano:**
  - *"Oh no, my bicycle has a flat tire!"*
  - *"We don't have enough colored markers for the poster."*
  - *"The science lab door is locked."*
- **Sugerir soluciones inmediatas:**
  - *"Don't worry! We can ask Mr. Davis for the spare key."*
  - *"Why don't we walk to school instead? It only takes ten minutes."*
  - *"If we share our pencils, we can both finish on time."*
- **Evaluar y acordar la solución:**
  - *"Good idea, let's do that right now."*
  - *"That's much faster. Let's try it."*

## 2. Pautas Pedagógicas
- Utilizar tarjetas de dilemas reales (olvidos de tareas, transporte demorado, clima adverso) para incentivar la interacción espontánea.
- Fomentar la actitud de colaboración y empatía mediante expresiones como *"Don't worry"* y *"We can solve this together"*.
