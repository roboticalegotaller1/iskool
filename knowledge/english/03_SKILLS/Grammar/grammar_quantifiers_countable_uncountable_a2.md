# Countable and Uncountable Nouns with Quantifiers (A2)

## 1. Alcance Curricular y Reglas Estructurales
- **Nivel CEFR:** A2 (Plataforma).
- **Reglas de Clasificación Sustantiva:**
  - Sustantivos Contables (*apples, sandwiches, students*): admiten singular con *a/an*, plural con *-s*, y número exacto (*three books*).
  - Sustantivos Incontables (*water, milk, bread, rice, information, homework, money*): no admiten plural ni número directo (*\*two milks*).
- **Matriz de Cuantificadores A2:**
  - **Some:** Afirmativas (*"I have some apples / some water"*).
  - **Any:** Negativas y preguntas (*"I don't have any money"*, *"Do you have any questions?"*).
  - **Many / A few:** Solo para contables plurales (*many chairs, a few friends*).
  - **Much / A little:** Solo para incontables (*not much time, a little juice*).
  - **A lot of / Lots of:** Para ambos grupos (*a lot of books, a lot of milk*).

## 2. Pautas Pedagógicas
- Prestar atención a sustantivos que son contables en español pero incontables en inglés (*homework, information, advice, furniture*).
- Contextualizar mediante la creación de listas de compras y recetas de cocina para preparar pizzas o ensaladas.
