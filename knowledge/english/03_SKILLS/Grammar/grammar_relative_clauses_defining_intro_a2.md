# Defining Relative Clauses: Who, Which, That, Where (A2)

## 1. Alcance Curricular y Reglas Estructurales
- **Nivel CEFR:** A2 (Plataforma).
- **Asignación de Pronombres Relativos:**
  - **Who / That:** Para personas (*"A chef is someone who cooks in a restaurant"*).
  - **Which / That:** Para cosas y animales (*"This is the mobile phone which has a great camera"*).
  - **Where:** Para lugares (*"A library is a quiet place where people borrow books"*).
- **Función Sintáctica en A2:** Proporcionar información esencial que identifica con exactitud de quién o de qué se está hablando, eliminando oraciones repetitivas.

## 2. Pautas Pedagógicas
- Utilizar el juego de las adivinanzas (*Riddle Challenge*): cada estudiante escribe 3 definiciones con *who*, *which* o *where* para que el resto del grupo adivine el objeto o profesión.
- Recordar que en oraciones de relativo especificativas básicas de A2 no se colocan comas separadoras.
