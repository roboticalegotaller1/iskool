# Connected Speech: Consonant-to-Vowel Linking, Intrusion and Auxiliary Weak Forms

## 1. Descriptores Can-Do
- El estudiante articula frases fluidas encadenando sonidos finales consonánticos con vocales iniciales contiguas (*Catenation*), eliminando pausas artificiales o golpes glotales (*"Hold on a minute"* se pronuncia */həʊld.ɒn.ə.mɪn.ɪt/*).
- Utiliza las formas débiles (*Weak Forms*) con la vocal neutra schwa `/ə/` para palabras gramaticales no acentuadas:
  - `to` → `/tə/`
  - `was` → `/wəz/`
  - `can` → `/kən/` (frente a la forma fuerte acentuada `/kæn/` o negativa `/kɑːnt/`)
  - `been` → `/bɪn/` o `/bən/`
- Reconoce estos fenómenos en audios auténticos para no confundir palabras fusionadas.

## 2. Pautas Pedagógicas
- **Práctica de Shadowing:** Repetición acompasada de oraciones cortas con metrónomo para internalizar el ritmo acentual del inglés (*Stress-timed rhythm*).
- Progresión desde [[pronunciation_word_stress_two_syllables_a1]] y [[pronunciation_past_ed_endings_a2]].
