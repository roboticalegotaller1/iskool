# Cambridge English B2 First Handbook for Teachers

## Ficha Bibliográfica Institucional
- **Autor Institucional:** Cambridge Assessment English / UCLES.
- **Año:** 2024 (Edición para docentes).
- **Acceso:** Especificaciones y lineamientos públicos oficiales para profesores.
- **Alcance Curricular:** Define la progresión para hablantes independientes que consolidan el nivel B2, incluyendo escalas de evaluación para expresión escrita (ensayo argumentativo, artículo, reporte) y expresión oral (discusión colaborativa, turnos largos).
- **Uso en iSchool:** Referencia comparativa de estándares de desempeño y progresión léxico-gramatical sin reproducción de materiales comerciales con derechos reservados.
