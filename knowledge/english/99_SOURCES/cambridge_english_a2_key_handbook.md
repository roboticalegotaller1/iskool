# Cambridge English A2 Key (KET) Handbook for Teachers

## Ficha Bibliográfica Institucional
- **Autor Institucional:** Cambridge Assessment English / UCLES.
- **Año:** 2024.
- **Acceso:** Especificaciones de evaluación curricular y pedagógica oficial para A2 Key / Key for Schools.
- **Alcance Curricular:** Descriptores para estudiantes de secundaria inicial y adolescentes en nivel A2: interacción en situaciones sociales básicas, expresión de opiniones y razones sencillas, comprensión de textos informativos breves, notas y mensajes informales, uso de modales (*should, must, have to*), primer condicional y verbos con infinitivo/gerundio.
- **Uso en iSchool:** Calibración curricular y formativa para Secondary 1 (A2 Key target).
