# Evaluación Formativa y Rúbricas (07_ASSESSMENT)

Este directorio alberga los criterios analíticos, listas de cotejo y escalas de valoración formativa para el aprendizaje del inglés en iSchool.

## Instrumentos de Evaluación
- `oral_production_rubric`: Evaluación de pronunciación, fluidez, rango léxico y precisión gramatical en producción hablada.
- `writing_analytic_rubric`: Evaluación de adecuación a la tarea, coherencia y cohesión, riqueza de vocabulario y corrección sintáctica.
- `formative_observation`: Guía de observación docente en el aula para educación temprana.
- `peer_review_checklist`: Pautas de coevaluación entre pares para proyectos colaborativos.
- `portfolio_evidence`: Criterios para el portafolio digital de evidencias de aprendizaje.
