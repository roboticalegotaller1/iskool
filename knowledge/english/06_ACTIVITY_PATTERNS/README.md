# Patrones de Actividades Interactivas (06_ACTIVITY_PATTERNS)

Este directorio cataloga las estructuras y recetas interactivas que el Motor de Inteligencia Artificial Pedagógica utiliza para armar desafíos, lecciones y reactivos.

## Patrones Catalogados
- `listen_and_point`: Selección visual guiada por audio para Pre-A1 / A1.
- `information_gap`: Actividad en parejas donde cada participante posee información complementaria.
- `guided_debate`: Estructura argumentativa por roles para niveles B1 a C1.
- `storyboard_creation`: Secuenciación narrativa con viñetas y descripciones escritas.
- `roleplay_dialogue`: Simulaciones situacionales (compras, viajes, resolución de conflictos).
- `gamified_quest_challenge`: Misión interactiva con recompensas de XP y monedas en el estudio de actividades.
