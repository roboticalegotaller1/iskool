# Cartographie Curriculaire Lycée / Bachillerato - Français B1 vers B2

## 1. Objectifs de Cycle Bachillerato (Lycée)
- Lycée 1 (40 semaines) : Consolidation B1 et amorce B2 (DELF B1 / CENNI 12-13). Argumentation simple, compte-rendu, lettre formelle.
- Lycée 2-3 : Maîtrise B2 complète (DELF B2 / CENNI 15-16). Débat citoyen, analyse de presse, synthèse documentaire.
